# Google Advanced Data Analytics — Python Coursework

This repository contains my **Python coursework, practice notebooks, and end-of-course projects** completed as part of the **Google Advanced Data Analytics Professional Certificate**.

The coursework builds progressively from Python programming and data manipulation to exploratory data analysis, statistical inference, regression, and machine learning.

---

## 📚 Courses & Topics

### Course 2 — Python Fundamentals

Built the foundation for using Python in data analysis.

- Python syntax, variables & data types
- Functions and conditional statements
- Loops and string manipulation
- Lists, tuples, dictionaries & sets
- NumPy arrays and vectorized operations
- pandas DataFrames
- Data selection with `.loc`, `.iloc` & Boolean masking
- Grouping and aggregation
- Merging and joining DataFrames

**End-of-Course Project:**  
**TikTok Claims Classification — EDA**  
Applied Python, NumPy and pandas to explore TikTok videos, investigate claim vs. opinion patterns, analyze engagement, handle missing data, engineer features, and communicate findings using the PACE framework.

---

### Course 3 — Exploratory Data Analysis & Data Cleaning

Focused on preparing real-world datasets for analysis and modeling.

- Dataset exploration and structuring
- Datetime manipulation
- Data transformation
- Concatenation, merging & joining
- Missing-value analysis and treatment
- Duplicate detection and removal
- Outlier detection using IQR
- Categorical encoding
- Data validation and standardization
- Exploratory visualization

**End-of-Course Project:**  
**TikTok Exploratory Data Analysis** — investigated relationships between claim status, verification, author ban status, and video engagement.

---

### Course 4 — The Power of Statistics

Applied statistical concepts using Python, NumPy, pandas, SciPy and statsmodels.

- Descriptive statistics
- Mean, median, variance & standard deviation
- Probability distributions
- Normal distribution and empirical rule
- Z-scores and outlier detection
- Random sampling
- Sampling distributions
- Central Limit Theorem
- Standard error
- Confidence intervals
- Hypothesis testing
- One- and two-tailed tests
- One- and two-sample t-tests

**End-of-Course Project:**  
**TikTok Hypothesis Testing** — tested whether video view counts differed significantly between verified and unverified accounts.

---

### Course 5 — Regression Analysis

Introduced statistical modeling and predictive analysis.

- Simple linear regression
- Multiple linear regression
- OLS with statsmodels
- Categorical predictors
- Regression diagnostics
- Model assumptions
- Multicollinearity and VIF
- One-way & two-way ANOVA
- Tukey HSD
- Binomial logistic regression
- Confusion matrices
- Precision, recall, F1 & ROC-AUC
- Odds ratios

**End-of-Course Projects:**

- **Marketing Sales Analysis** — regression and ANOVA
- **Diamond Price Analysis** — one-way and two-way ANOVA
- **Invistico Airlines** — customer satisfaction prediction
- **TikTok Logistic Regression** — predicting account verification status

---

### Course 6 — Machine Learning

Applied supervised and unsupervised machine learning techniques in Python.

- Feature selection, extraction & transformation
- Feature engineering
- Naive Bayes
- K-means clustering
- Decision trees
- Random Forest
- XGBoost
- Hyperparameter tuning with `GridSearchCV`
- Cross-validation
- Model evaluation
- Feature importance
- Confusion matrices and classification metrics

**End-of-Course Projects:**

- **Bank Customer Churn** — feature engineering, Naive Bayes & decision trees
- **NBA Career Longevity** — feature engineering & Naive Bayes
- **K-means Color Compression** — unsupervised learning applied to image data
- **TikTok Claims Classification** — Random Forest & XGBoost with text features and recall-focused evaluation
